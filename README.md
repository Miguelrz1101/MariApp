# Aprende con Mariangel (Android, 100% offline)

- `www/index.html`: la app (sin dependencias en línea).
- Tailwind y fuentes (Fredoka/Nunito) se compilan/copian localmente en el build.
- Voz: TextToSpeech nativo de Android (requiere voz en español instalada en el dispositivo).
- Cada push a `main` compila el APK en GitHub Actions → Artifacts.
